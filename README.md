# Business-Insights-360
Welcome to Business Insights 360 - Data Driven Desicion Making Dashboard
This is a business intelligence and data analytics project focused on delivering a complete view of organizational performance using data visualization, KPI tracking, and insightful reporting.
## Live Dashboard 📊📈📉
Have a look into interactive dashboard - [Dashboard Link](https://app.powerbi.com/groups/me/apps/84172b63-a455-475e-aebc-245906920ba3/reports/decafffc-d48c-4514-b1ea-984472e51c81/455a87b7299ddae4e04b?ctid=27786721-bb1a-46c6-916a-da82f5c834a9&experience=power-bi)

## Pages in Report 📄📃

 💰Finance View - Explore P&L statements, product analysis, and net sales trends.

 🛒Sales Vies - Analyze the performance of your customer(s) over key metrics like Net Sales, Gross Margin and view the same in profitability / Growth matrix.

 📢Marketing View - Analyze the performance of your product(s) over key metrics like Net Sales, Gross Margin and view the same in profitability / Growth matrix.

 🚚Supplychain View - Get Forecast Accuracy, Net Error and risk profile for product, segment, category, customer etc.

 💼Executive View - A top level dashboard for executives consolidating top insights from all dimensions of business.

## Data Sources
  Two main sources from which Data gathered for designing this dashboard are,
  1. **Excel/CSV Files**: Targets and Market Share data, along with related information, are collected from Excel and CSV files.
  2. **MySQL Database**: Essential facts and dimensions for all departments are pulled from a MySQL database.
